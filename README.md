## 安装

1. 下载并打开 DMG。
2. 将「水豚噜噜.app」拖入「应用程序」。
3. 从「应用程序」打开噜噜，然后推出 DMG。

这是采用本地签名的内测版，没有 Apple Developer ID 签名或苹果公证。首次打开可能被 macOS 安全机制拦截；不能承诺双击即可运行。仅在你信任来源并核对发布页校验值后，按 [Apple 的安全打开说明](https://support.apple.com/en-gb/102445) 操作。请勿关闭 Gatekeeper，也不要运行来源不明的“修复”命令。
